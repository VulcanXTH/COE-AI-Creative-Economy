ตารางอัตรากำลัง (Org Chart + FTE) — ฉบับ v2 กรอบ Leverage

คณะทำงานขับเคลื่อนปัญญาประดิษฐ์ด้านอุตสาหกรรมสร้างสรรค์ (Creative Economy) · 17 มิ.ย. 2569 · (แทนที่ไฟล์ 41)
หลักการ FTE ใหม่: โครงการเรือธงส่วนใหญ่เป็น กลไกบริหารงบ + ตรวจสอบ (audit) + วัดผล บนกลไกของหน่วยงานเจ้าของกองทุน — ไม่ใช่สร้างแพลตฟอร์ม/โมเดลเอง → อัตรากำลังเล็กลงราวครึ่งหนึ่งของแผนเดิม (จาก ~77 เหลือ ~40 FTE core)

3. อัตรากำลังปฏิบัติการ (FTE)

หน่วยปีที่ 1เต็มรูปแบบที่มาหลักของคน
สำนักงานเลขานุการ / PMO กลาง510จ้างใหม่ + เจ้าหน้าที่ AICAT/สดช.
ทีมเลขานุการอนุทำงาน 4 ชุด48in-kind หน่วยเจ้าภาพอนุ
ทีมโครงการเรือธง 4 ทีม~11~22
  ① Voucher (บริหารโปรแกรม + audit คูปอง)36จ้างใหม่ + in-kind สสว./depa
  ② Cash Rebate (บริหารกองทุน + ตรวจค่าผลิต)47จ้างใหม่ (การเงิน/audit) + in-kind BOI
  ③ Dub-Thai Export (ประสานผลิต + ตลาด)36จ้างใหม่ + เครือข่าย สคต. (DITP)
  ④ Game Accelerator (เติม track บน depa)13in-kind depa เป็นหลัก
รวม FTE core~20~40+ pool/จ้างเหมา (audit, mentor, QA ภาษา, ประเมินผล)

4. ที่มาของกำลังคน (เต็มรูปแบบ)

ประเภทสัดส่วนตัวอย่าง
In-kind หน่วยงานเจ้าของกองทุน~40%เจ้าหน้าที่ สสว./depa/BOI/DITP ที่บริหารโปรแกรมเดิม
จ้างใหม่ (โครงการ/สัญญาจ้าง)~35%PMO, นักการเงิน/ตรวจสอบ, ผู้ประสานตลาด, M&E
จ้างเหมา / ผู้ตรวจสอบอิสระ~15%audit ค่าผลิต (rebate), QA ภาษา (dubbing)
Pool ผู้เชี่ยวชาญ/ครูพี่เลี้ยง~10%mentor (voucher), ผู้ประเมินผล

เปลี่ยนจากเดิม: ไม่มีทีม Foundation Model 16 คน (ยกเป็นวาระระยะยาว) · ไม่มี PCO จัด Summit (ตัดออก) · เพิ่มน้ำหนักงาน audit/การเงิน ตามโมเดลจ่ายเมื่อเกิดผล · ตัวเลข FTE เป็นประมาณการ กำหนดจริงหลัง Feasibility (Gate เดือน 6)
